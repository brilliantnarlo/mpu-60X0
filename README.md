# mpu-60X0
MPU6050 is an accelerometer gyroscope, and temperature sensor.

The CPU Architecture design is not the actual MPU6050 architecture because MPU6050 is not open source.

This project was made possible from reading the open source register map.

This project focuses on implementing the register address, map but not the actual instruction functionality.
